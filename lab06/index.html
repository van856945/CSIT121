Lab 03 Reflection

In Lab 03, I learned how to use CSS to change the appearance of a webpage. I learned how to use an external stylesheet to change colors, fonts, backgrounds, and links. I also learned that using external CSS makes it easier to keep a website organized and consistent.

What I Learned

  • How to create an external CSS file
  • How to style HTML elements with CSS
  • How to use ID and class selectors

Lab 05 Reflection

In Lab 05, I learned that good web design should be easy to use on both phones and computers. Using a simple layout, readable fonts, and clear navigation makes a website easier to understand. I learned that keeping things organized and making links easy to find are important design practices. Testing a website on different screen sizes also helps make sure people can use it easily.

What I Learned

  • Why websites should be easy to navigate
  • How to keep a layout simple and organized
  • Why readable text and good spacing matter
